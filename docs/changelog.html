Changelog

Complete history of changes, fixes, and additions.

Version: v1.0.4 + Unreleased ← Back to Documentation

[Unreleased] — Sunstrider Cleanup and Documentation Alignment

  • [Cleanup — Remove Redundant Sunstrider Overrides] Removed temporary uiMapIdToAreaId entries for Sunstrider Isle (1241 -> 3430, 946 -> 3430) from Zones/AscensionZoneTables.lua.
  • [Why] The active fix path now lives in Questie-X core, which performs the per-zone ghost-map handling, reverse-map resolution, and compatibility-layer work locally. Keeping duplicate plugin-side overrides in AscensionDB risked documentation drift and obscured the real root cause.
  • [What did not work / learned] Treating AscensionDB as the primary place to solve the current Sunstrider arrow regression was a dead end. The remaining failures were in Questie-X core tooltip, arrow, map, and compatibility layers — not in the plugin database.

v1.0.4 — Realm Check Fix

  • [Fix — Realm Allowlist] Extended realm allowlist in AscensionLoader.lua and AscensionUiMapData.lua to include CoA, Conquest, and Vol realm-name substrings.
    • This allows the plugin to activate on Vol'jin - CoA Beta and other Conquest-of-Azeroth realm variants that were previously skipped.
    • The plugin now matches the broader realm naming used by current Ascension / CoA deployments instead of relying on a single exact label.

v1.0.3 — Initialization Stability and Visibility Fix

  • [Fix — Database Compilation] Database compilation is now deferred to Stage 3 on WotLK/Ascension clients. This ensures the compilation progress log is fully visible in the chat frame after login.
  • [Fix — Stage 2 Initialization] Resolved Stage 2 initialization crash by ensuring l10n and QuestieCorrections are initialized during deferred flow.
  • [Fix — ZoneDB pairs Error] Fixed "bad argument #1 to 'pairs' (table expected, got nil)" in zoneDB.lua by initializing QuestPointers as an empty table in the dummy block.
  • [Stability — Comprehensive Dummy Handles] Implemented comprehensive dummy handles and pointers in QuestieDB.lua to prevent downstream crashes while the database is being compiled.
  • [Fix — Stage 3 Guarded Initialize] Added guarded QuestieDB:Initialize() call in Stage 3 to ensure handles are properly set up after late compilation.

v1.0.2 — Injection and Newline Fixes

  • [Fix — Hidden Literal Newlines] Fixed hidden literal newline characters (\\n) in the rechunking script that were causing all split files to load as a single comment block.
  • [Fix — Database Injection Casing] Corrected database injection casing in AscensionLoader.lua to match QuestiePluginAPI requirements (QUEST, NPC, OBJECT, ITEM).
  • [Fix — InjectUiMapData Call] Restored InjectUiMapData call to ensure zone boundary data is correctly loaded.

v1.0.1 — Architecture Update

  • [Performance — Split Database Files] Split monolithic database files into smaller chunks to resolve memory allocation errors.
  • [Architecture — Split-Loading Architecture] Adopted the split-loading architecture (like WotLKDB) to reduce initial memory footprint and load times.
  • [Loader — Dynamic addonTable Injection] Updated AscensionLoader.lua to dynamically inject addonTable populated by split files.

v1.0.0 — Initial Release

  • [Quests — Initial Ascension Quest Loading] Initial Ascension quest database for quest tracking, map pins, and tooltips.
  • [Core — Created Questie-X-AscensionDB] Initial plugin implementation using QuestiePluginAPI for server-specific data injection.
